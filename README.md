# dpdk-packet-reader

Читалка пакетов на основе примера `basicfwd` из DPDK, написанная как тестовое задание в 2023 году.
Программа принимает заданное число кадров и записывает разобранный дамп в `ans.txt`: заголовки
Ethernet, IPv4, UDP и TCP, а также содержимое пакета в шестнадцатеричном виде.

## Сборка и запуск

Нужны DPDK и `pkg-config`. Проверено на DPDK 21.11.9 и Ubuntu 22.04.

```bash
make
echo 12 | ./build/basicfwd -l 0 --no-huge --no-pci -m 256 --no-telemetry \
    --vdev "net_pcap0,rx_pcap=sample/sample.pcap"
```

Программа читает число кадров из stdin и завершается, когда примет столько кадров. Для чтения из
pcap-файла нужен драйвер DPDK `net_pcap`. Для работы с реальным портом уберите опции `--vdev` и
`--no-pci`.

## Об истории коммитов

Я написал этот код и отправлял его вложениями в письмах, поэтому в git его не было. Коммиты
с датами 2023 года восстановлены из этих трёх писем с помощью Claude:

| Дата | Изменение |
|---|---|
| 29.07.2023 | Первая версия |
| 31.07.2023 | Исправлена длина TCP-заголовка: data offset умножается на 4, а не на 5 |
| 01.08.2023 | Исправлен разбор размера окна и портов |

Код в этих коммитах в точности совпадает с вложениями, а даты совпадают с датами отправки писем.

`ans.txt` появился не в 2023 году. Исходные дампы не вошли в репозиторий: в них SIP-трафик
неизвестного происхождения с логином, digest-ответами и телефонными номерами. Вместо этого каждая
версия была собрана и запущена в 2026 году на `sample/sample.pcap`, а её вывод лежит в
соответствующем коммите, поэтому в диффах видно, что изменило каждое исправление.
`sample/generate_sample.py` создаёт этот файл из синтетического трафика с адресами, зарезервированными
для документации.
